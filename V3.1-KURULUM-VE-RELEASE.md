# AYK Muhasebe Yardımcısı V3.1

## Bilgisayarda npm kullanılmaz
Dosyaları GitHub deposunun ana dizinine yükleyin. Derlemeyi GitHub Actions yapar.

## Normal EXE derleme
Actions > Windows EXE Derle > Run workflow

Artifact içinde:
- AYK-Muhasebe-Yardimcisi-Setup-3.1.0-x64.exe
- AYK-Muhasebe-Yardimcisi-Portable-3.1.0-x64.exe
- latest.yml
- blockmap

## Release yayınlama
1. package.json sürümünün 3.1.0 olduğunu doğrulayın.
2. v3.1.0 etiketi oluşturup gönderin.
3. Windows Release Yayınla otomatik çalışır.
4. Release Assets altında Setup EXE, Portable EXE, latest.yml ve blockmap görünmelidir.

## Otomatik güncelleme
Otomatik güncelleme yalnızca Setup sürümünde test edilmelidir. Portable sürüm kendini güvenilir biçimde güncellemez.
