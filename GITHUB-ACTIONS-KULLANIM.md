# GitHub Actions ile EXE Alma

## İlk test derlemesi

1. Bu paketin içindeki tüm dosyaları GitHub deposuna yükleyin.
2. Commit mesajı olarak `V3.0 GitHub Actions EXE derleme altyapısı` yazın.
3. **Actions** sekmesine girin.
4. **Windows EXE Derle** seçeneğini açın.
5. **Run workflow → Run workflow** düğmesine basın.
6. Yaklaşık birkaç dakika sonra iş akışı yeşil tik göstermelidir.
7. Çalışmanın en altındaki **Artifacts** bölümünden ZIP dosyasını indirin.

## Çıktılar

- Kurulumlu Windows EXE
- Portable Windows EXE
- Otomatik güncelleme için YAML/blockmap dosyaları

## Hata olursa

Actions çalışmasını açın ve kırmızı görünen adımı seçin. Hata metninin ekran görüntüsünü veya son bölümünü paylaşın.
